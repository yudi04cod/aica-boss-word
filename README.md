# Aica Boss Word

One word describing a boss: **Delegator** — the boss who passes every
task down the chain and keeps only the credit. Funny on its own, true
in every office, kitchen and warehouse, and fresher than the first
word anyone reaches for.

`main.py` (Python 3, standard library only, deterministic) scores a
shortlist of candidate words against the judge's five criteria and
writes the winner — exactly one word, 9 characters — to
`/output/entry.txt`.

Built for the [make.fun](https://make.fun) competition
[u-swift-badger-44-one-word-for-the-boss-6b48c735](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

Referral code: 38m33ybw

## The entry

> Delegator

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
